# Phase 1 — Domain
Mission Statement - This database will hold the information of all 151 Pokémon and their move sets for the player's reference. 

Mission Objectives:
1. Catalogue Pokémon names
2. Store Pokémon stats
3. Catalogue Pokémon movesets
4. Catalogue Pokémon types
5. Catalogue Pokémon abilities

Domain Description - This domain will store all of the in-game data for the Pokémon in FireRed and LeafGreen so the player can easily look up needed information.
